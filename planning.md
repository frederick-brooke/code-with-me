Project Name: Code with me
Description: Code with me is a nextjs typescript web application which is a mock live coding inverview. The app is used to help interview candidates prepare for the technical coding interview with an assessor. 

# Core Features
- Basic code editor (python). 
- An AI voice agent as an assessor and interviewer to introduce the leetcode style problem, answer questions the user has, help guide the user through the technical problem when candidate asks questions without simply giving the answer away. 
- A code compiler to run the candidates code to test the solution. 
- After the interview provide a summary of candidate performance: What went well, Even better if, problems, technical review of solution.
- Save user progress in a database
- User able to select from multilpe leetcode style questions
